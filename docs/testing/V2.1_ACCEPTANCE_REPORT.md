## 4. 未完成 / 明确边界（不要报成已完成）

1. **自动修复循环**：Review 判「需修复」后不会自动重跑计划。理由：当前审批粒度是整份计划，自动循环会绕开用户确认。要做得先做逐步审批。
2. **Model Router**：没有按任务自动选模型，仍由研究设置或 hybrid 主导选择器决定。
3. **AST / 符号索引 / 调用图 / 向量库**：按 Phase E 要求没有引入。当前是「真实文件读取 + 关键词检索 + 内容指纹」。
4. **证据库 / 跨会话检索（P5）**、**多轮自主研究（P6）**：仍未做。
5. **`compare` / `extract` 专属行为**：四类知识意图仍共用一条链路，只有 `answer` 是认真分化的；V2.1 没有要求改变这点，但也没有新增对比表或网页抓取。
6. **S-04 对抗测试**：只做了结构性验证（schema、路径、allowlist），没有拿一段恶意网页文本实测注入是否会影响计划内容。
7. **多通道真机端到端**：本轮真机验证不发送任何问题（避免往用户账号写测试题）；三通道同时登录后的完整问答链路未在本轮复测。
