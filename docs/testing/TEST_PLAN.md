# 测试计划（Phase K）

日期 2026-11-04。对应项目书第十五章 Phase K 的 17 项场景，以及第十六章验收。

## 分层

| 层 | 入口 | 依赖 |
| --- | --- | --- |
| 逻辑回归 | `npm test`（含 `test:debate-lead` 在内的全部检查脚本，319 条） | 无 |
| 真实响应回放 | `test:ollama`（本机录制的 Ollama payload）、`test:cloud`（OpenAI 文档结构） | 无 |
| 真机端到端 | `test:ollama:live` / `test:cloud:live` / CDP 脚本 | Ollama 服务 / API Key / 已登录网页 |
| 静态检查 | `npm run typecheck` / `npm run build` | 无 |

`test:cloud:live` 没有 `CLOUD_API_KEY` 时整组 skip，不把「没跑」写成通过。
任何会在网页侧留下会话的真机脚本都不进 `npm test`；跑完必须用
`agentAPI.deleteConversation` 清理，并回读应用侧与网页侧确认。

## 17 项场景

| # | 场景 | 方式 | 通过标准 |
| --- | --- | --- | --- |
| 1 | Web 模式回归 | 真机 | 三网页通道都回答、综合生成、删除无残留 |
| 2 | Local 模式 | 真机 | 只走 Ollama，回答正确 |
| 3 | Cloud 模式 | 逻辑 + live 脚本 | 无 Key 时如实 skip |
| 4 | Hybrid 模式 | 真机 | 网页 + 本地同时参与 |
| 5 | 多模型并行 | 真机 + 逻辑 | 所有成员都被问到、按并发上限分批 |
| 6 | 多轮辩论 | 逻辑 + 真机 | 三种策略轮数、后轮带前序；三种主导方式各自跑通、网页侧记录清理干净 |
| 7 | 模型中途失败 | 逻辑 | 失败隔离、重试一次、他人照常完成 |
| 8 | 网络中断 | 逻辑 | `unavailable`，不抛裸 fetch 错 |
| 9 | Ollama 退出 | 逻辑 | `health().available === false` |
| 10 | API 限流 | 逻辑 | 429 重试后成功、耗尽报 busy |
| 11 | 用户取消 | 逻辑 | 中止为 stopped、恢复不重跑 |
| 12 | 应用重启 | 真机 | 会话、状态、执行配置读得回来 |
| 13 | 历史记录恢复 | 真机 + 逻辑 | 辩论/裁决/Key 从盘上重建 |
| 14 | 隐私模式 | 真机 + 逻辑 | `local-only` 下不外发 |
| 15 | 超长网页内容 | 逻辑 | 400 段不崩、收尾话不当观点 |
| 16 | Token 预算耗尽 | 逻辑 | 达到上限后不发请求 |
| 17 | 多个 Conversation 同时执行 | 逻辑 | 状态不串台 |

## 验收口径

- 「通过」只标有测试或真机输出的；计划实现但没跑的写「未验证」。
- 真机产生的会话、网页侧记录、临时脚本全部当场清理。
- 不 push；本地提交由 AI 完成，推送留给用户。
