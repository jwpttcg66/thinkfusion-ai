# V3 辩论与审核按需触发、去重及预算控制

基线：`main@6a15b9a` · 分支：`feat/v3-collab-budget-control`

## 问题

小任务也会进入庞大协作结果：`auto` 与 `on` 同等启动五段模型评审；执行后审核无条件调模型；
结果面板把成员补充摘要全部标成「核心意见」，意见数 ≠ 争议数。

## 硬规则

1. 简单任务优先单模型、直接执行；`auto` 不得为「是否辩论」先花一次模型调用。
2. 辩论不是默认阶段；无影响目标的实质争议不启动。
3. 审核不是重复执行；规则优先，模型只处理规则判不清的重要风险。
4. 每个问题只处理一次；无新证据不重复审核/辩论。
5. 循环必须有收益；否则停止并留下停止原因。

## 任务分级（启发式，不调用模型）

| 等级 | 典型特征 | 方案评审（auto） | 模型审核 |
| --- | --- | --- | --- |
| L0 | 只读/极少步/无写盘与桌面操作 | 整段跳过 | 规则即可 |
| L1 | 小范围写入且计划带观察动作 | 最多 1 轮上限 | 验证通过且规则无问题则跳过 |
| L2 | 多步改动 / 缺判据 / 多模块迹象 | 最多 2 轮 | 按需一次 |
| L3 | 设计文档 / 删除·杀进程·高风险词 / 桌面控制链 | 最多 3 轮 | 按需一次 |

- 不削弱 L3 高风险任务的深度协作
- 不把「展示去重」当成「执行未调用」的替代
