# P5 模型与通道

目标：把「网页渠道」和「模型驱动」分开；模型范围内（local / remote / hybrid）按任务选人，新增通道不改主流程。
前置：P1 引擎稳定、P4 证据统一。
出口：新增一个来源只加 Adapter 与能力描述。

---

## 1. 两个维度：渠道类型 vs 调用范围

不要把它们混成一个分类：

```text
来源类型
├── 网页渠道（页面驱动）
└── 模型驱动
    ├── 本地模型
    ├── 远端模型
    └── CLI（也是模型驱动）

调用范围（只对模型驱动生效）
├── local  只调本地模型
├── remote 只调远端模型
└── hybrid 本地 + 远端都可调
```

**网页是渠道，不是模型。** 是否参与由任务决定；不因为 `hybrid` 就自动加入。

`ModelScope` / `AgentCapabilities` / `Policy` 的权威定义见
[P1-002 §3.1/§3.2](P1-002-DOMAIN-RUNTIME-CONTRACT.md)；本章只列路由规则。

| 来源 | 驱动 | system | 工具 | 流式 | 看他人 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| 网页渠道 | 页面 | ✗ | ✗ | 轮询增量 | ✗ | 只收原话或系统转述的数据块 |
| 本地模型 | 模型 | ✓ | ✓ | ✓ | ✓ | 只在 `local` / `hybrid` 下可选 |
| 远端模型 | 模型 | ✓ | 视模型 | ✓ | ✓ | 只在 `remote` / `hybrid` 下可选 |
| CLI（只读） | 模型 | ✗ | ✗ | ✗ | ✗ | 回答源；临时目录；按范围归类 |
| CLI（执行） | 模型 | — | ✓ | ✗ | — | 走 TaskGrant/审批，不在本能力表 |

规则：

- **先守范围，再按能力**：`local` 不得选远端模型，`remote` 不得选本地模型；
  只有 `hybrid` 可混用。网页是否参与看 `includeWeb`，与范围无关。
- 能力由 Adapter 声明，调度器只读声明，不猜。
- 网页通道 `canSystemPrompt=false`、`canUseTools=false`；任何需要工具的任务不得分配。
- 降级（模型不可用、LSP 不可用、页面结构变化）必须显式记录；降级不得越界
  （`local` 不能因为本地不可用就悄悄改用远端，只能标失败/阻塞）。

---

## 2. 路由与降级

顺序：

1. **先定范围**：Planner 写出 `Policy`（modelScope + includeWeb + allowWebQuestioner）。
2. **再定名单**：在范围内按能力、负载、成本选人；Scheduler 不得越界增删。
3. **降级阶梯**（每级都要说出来，且不能越界）：
   - 首选模型不可用 → 同范围内的次选；
   - 本地不可用（`local`）→ 阻塞或失败，不得改用远端；
   - 工具不可用 → 文本搜索，并标 `degraded`；
   - 全部不可用 → 任务 `skipped`，交付物写缺口。

禁止：静默越界、静默改用低质量模型、静默减少参与者、把降级结果标成正常。

---

## 3. 新增一个通道

步骤固定，不允许改主流程：

1. 在 `providers/` 或 `adapters/` 加 Adapter（选择器/接口/错误归一）；
2. 声明 `AgentCapabilities`；
3. 加来源配置（`shared/sources.ts` 或设置页默认值）；
4. 加单测（取回答、失败、超时）；
5. 加 live 检查（可选，登录态下）；
6. 不改 Planner/Scheduler/Verifier。

验收：新增一个 mock 通道，只需 Adapter + 能力声明；选择理由可读、跳过有原因。

---

## 4. 配置与可观察

- 每个通道显示：启用/可用/健康/最近失败原因；
- 模型选择理由可读（谁、为什么、降级了吗）；
- 费用/延迟按通道记录，不混淆网页（无 token）与 API（有 token）。

## 5. 场景与测试

- `check-channel-capabilities.mjs`：能力声明与调度过滤一致；
- `check-channel-fallback.mjs`：四级降级都有记录；
- `check-new-channel.mjs`：mock 通道只加 Adapter 即可跑通第一手；
- live：真实登录态至少一个网页 + 一个 API 模型。
