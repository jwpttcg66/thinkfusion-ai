# Phase J 实施记录：前端 UI

对应项目书第十二章、第十五章 Phase J。日期 2026-11-04。

## 入口与最小侵入

没有重做界面，只加了两处：

- 输入框上方一条 `.research-bar`：一个「研究设置」按钮 + 当前模式/隐私/策略的
  一行摘要（`privacyMode=local-only` 时多一个「不出本机」标记）。
- 一个 `ResearchPanel.tsx`，复用 `DiagnosticsPanel` 已有的 `.diag-*` 弹窗骨架，
  四个 tab。Esc 关闭、点遮罩关闭。

`App.tsx` 的 `submit()` 把 `executionConfig` 原样带进
`submitConversation()`；面板里的每次改动都过 `normalizeExecutionConfig()`，
所以非法值到不了 IPC。`Picker` 提到组件外定义——放在 render 里会让组件类型
每次都变，输入框会丢焦点。

## 四个 tab

| Tab | 内容 |
| --- | --- |
| 执行模式 | 四种模式、隐私模式（web 下禁用「仅本地」并说明理由）、fallback、协作策略、三组模型勾选、API Key 保存/移除 |
| 协作 | `getCollaborationRecords()` 的子任务表：状态、轮次、尝试次数、前序条数、耗时、失败原因 |
| 辩论 | 发起（问题/策略/轮数）、历史列表、停止/继续、逐轮时间线、少数派、裁决按钮与结果 |
| 报告与预算 | 最近一次 `Synthesis.fusion` 摘要（最终结论、置信度、证据/关系数、被否定观点、未解决问题、limits）、token/费用、各 Provider 状态 |

历史查看、实时通道状态、综合卡片沿用原来的 `ConversationView` 与
`channel.phase` 事件，没有另做一套。

## 预算统计

新增 `app:usage`，返回 `OpenAICompatibleProvider.usageSummary()`：
调用次数、输入输出 token、按币种汇总的费用、**服务端没给 usage 的次数**
单独计数（不把「不知道」当 0）。没有配置单价时费用写「未配置单价，不估算」。
没有云端 Provider 时返回 null，界面明说没有数据。

API Key 输入框是 `type=password`，面板只显示 `hasKey` 布尔，保存后立刻清空
本地 state，不回显、不写日志。

## 真机验证（CDP 读 DOM）

启动新构建后逐项点过：

- 设置栏初始文本 `研究设置 当前：网页 / 允许外发 / 默认并行`。
- 面板能打开；模式页渲染出网页/本地/云端/混合四个按钮、隐私模式、协作策略、
  三组模型清单、API Key 输入。
- 点「本地」后设置栏同步成 `当前：本地 / …`（说明配置确实会带进下一次提交）。
- 协作 / 辩论 / 报告与预算三个 tab 各自渲染出「子任务」「发起辩论」「预算统计」。
- 报告页显示 `云端调用 0 次 / Token 0 / 费用 未配置单价，不估算 / 来源状态`。
- 关闭后设置栏恢复网页模式，避免影响后续真机提问。

一处验证脚本的假警报：标题 `API Key` 被 CSS 转成大写，按原大小写匹配失败，
实际渲染正常。

## 验收对照（项目书 Phase J）

| 要求 | 状态 |
| --- | --- |
| UI 能完整操作四种模式 | ✅ 真机点过 |
| 启用和关闭辩论 | ⚠️ 辩论是独立面板（开始/停止/继续），不是提问时的开关 |
| 设置参与模型和轮数 | ✅ 三组勾选 + 轮数输入 |
| 能看到各轮发言 | ✅ 时间线 |
| 能查看最终裁决 | ✅ 裁决结果块 |
| 失败和取消状态正确展示 | ✅ 子任务表与辩论列表 |
| 历史查看 / 实时状态 / 最终报告 / 预算统计 | ✅ |

**一处与项目书的差异**：项目书把辩论写成「新建对话时的开关」。这里做成独立
面板，因为辩论是独立子系统（决策 2），它的参与者、轮数、停止/恢复都和一次
普通提问不同；塞进提问开关会把两套生命周期绑在一起。
