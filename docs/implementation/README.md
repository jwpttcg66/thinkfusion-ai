## 使用方式

1. 只从**当前阶段**取任务；前置门禁没过，不领后一阶段。
2. 每个任务开工前先读它的「依赖」与「回滚」；没有回滚点的任务不许开工。
3. 验收命令必须真实执行，不能以「代码看起来对」代替。
4. 实际代码与计划不一致时，先改计划再改代码，并在提交信息里写清原因。
