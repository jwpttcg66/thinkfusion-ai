# V3 支持矩阵

日期：2026-11-20。
用途：P6-08 发布门禁的支持范围；与 `RELEASE_OPERATIONS.md` 配套。

## 1. 运行环境

| 项 | 支持范围 | 说明 |
| --- | --- | --- |
| macOS | 当前主版本及前两个大版本 | 发布时确认；低于范围不保证 |
| 芯片 | Apple Silicon arm64 | Intel 不在 V3 发布范围 |
| Node | ≥ 22.12 | 仅开发/构建；打包不依赖本机 node_modules |
| Electron | 45.x | 与 `package.json` 一致 |
| 磁盘 | ≥ 2 GB 可用 | 证据包/索引/快照 |
| 内存 | ≥ 8 GB | 本地模型另计 |

## 2. 通道

| 通道 | 支持 | 限制 |
| --- | --- | --- |
| Web（网页） | 回答；知识/通用可提问 | 无 system/工具；工程只回答 |
| Local | 回答/规划/工具 | 受本机推理能力限制 |
| Cloud | 回答/规划/工具 | 需要 Key/登录 |
| CLI（只读） | 回答源 | 临时目录，不写工程 |
| CLI（执行） | 执行 | 必须审批 + 隔离 worktree |

## 3. 数据与迁移

- 数据 schema：`1`；
- 升级前备份；迁移失败保留备份并只读恢复；
- 降级：旧版本忽略未知字段，读不到模式文件即 `legacy`。

## 4. 发布门禁

`release-ops/gate.ts` 的 7 项必须全绿：

1. P0–P5 门禁；
2. 版本一致；
3. 产物已签名；
4. 干净机器安装；
5. 备份/恢复钻取；
6. 回滚钻取；
7. 发布说明。

## 5. 已知不在范围

- Intel Mac；
- 自动更新；
- Windows/Linux；
- 未签名/未公证的产物。
